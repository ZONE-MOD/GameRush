# GameRush — به‌روزرسانی فصل دوم

این بسته روی پروژه فعلی GameRush قرار می‌گیرد و صفحه بازی GitHub Pages را به‌روز می‌کند. برنامه اندروید همچنان همان آدرس قبلی را باز می‌کند تا داده‌های ذخیره‌شده بازیکن در همان مبدأ وب باقی بمانند.

## تغییرات

- اصلاح صفحه گردونه برای تمام‌صفحه شدن و اسکرول درست در حالت افقی و عمودی
- گردونه دایره‌ای با چرخش واقعی؛ هر چرخش فقط ۱ جم هزینه دارد و سکه برای چرخاندن پذیرفته نمی‌شود
- فروشگاه بسته‌های ۱۰۰۰، ۵۰۰۰، ۱۰۰۰۰، ۱۵۰۰۰ و ۲۰۰۰۰ جم
- تبدیل جم به سکه با نرخ ۱ جم = ۱۰۰ سکه
- تیک آبی با قیمت ۵۰۰۰ جم و افزایش نسبی ۲۰٪ شانس آیتم‌های اسکینی
- اسکین شیر تاریک و هلمت آتشین Inferno؛ هرکدام ۱۰۰۰۰ جم برای دارندگان تیک آبی، و شانس بسیار پایین در گردونه برای دیگران
- فصل دوم با دو مرحله: فرار از شیطان، دایناسور نجات‌دهنده و سفینه؛ سپس کات‌سین سفینه، گروه فضایی و فرود روی سیاره ارغوانی
- موسیقی و افکت‌های جداگانه برای سفینه، برخورد سنگ و صحنه‌های فضایی
- عبارت Zone در متن قابل‌مشاهده بازی وجود ندارد

## نکته پرداخت و کد

بسته‌های جم در این نسخه «آزمایشی» هستند و با لمس دکمه، جم تستی اضافه می‌شود؛ هیچ پرداخت واقعی انجام نمی‌شود. برای فروش واقعی جم باید درگاه پرداخت یا Google Play Billing و اعتبارسنجی سمت سرور به پروژه متصل شود.

کدهای آزمایشی محلی فقط جم اضافه می‌کنند:

- `RUSHGEM100` — ۱۰۰ جم
- `RUSHGEM500` — ۵۰۰ جم

این کدها در فایل HTML قرار دارند و برای انتشار عمومی امن نیستند؛ کد واقعی باید سمت سرور اعتبارسنجی شود.

## نصب تغییرات با Termux

۱. فایل ZIP را در پوشه Download گوشی قرار بده.

۲. Termux را باز کن و این دستورات را اجرا کن:

```bash
pkg update -y
pkg install git unzip -y
termux-setup-storage
cd "$HOME"
if [ -d "$HOME/GameRush/.git" ]; then
  cd "$HOME/GameRush"
  git pull origin main
else
  git clone https://github.com/ZONE-MOD/GameRush.git "$HOME/GameRush"
  cd "$HOME/GameRush"
fi
unzip -o /storage/emulated/0/Download/GameRush-Season2-Update.zip -d .
git add index.html dino-rush-beta.html app .github/workflows/build-apk.yml settings.gradle.kts build.gradle.kts gradle.properties README-Season2-FA.md
git commit -m "Add GameRush Chapter 2 and gem roulette"
git push origin main
```

اگر دستور `git commit` گفت چیزی برای ثبت وجود ندارد، یعنی فایل‌ها از قبل در مخزن ثبت شده‌اند؛ در این حالت `git status` را بررسی کن.

## بعد از Push

- GitHub Pages صفحه بازی را از `index.html` به‌روز می‌کند.
- GitHub Actions نیز با تغییر فایل‌ها APK نسخه ۲ را می‌سازد.
- APK در بخش Actions → اجرای موفق Build GameRush APK → Artifacts → `GameRush-Android-APK` قرار می‌گیرد.
- چون برنامه قبلی همان صفحه وب را از همان آدرس باز می‌کند، برای دیدن تغییرات سایت معمولاً نیازی به نصب دوباره APK نیست؛ برنامه را کامل ببند و دوباره باز کن.
- اگر خواستی APK جدید را نصب کنی و Android خطای امضا داد، نسخه قبلی را حذف نکن مگر اینکه از اطلاعات پروفایل مطمئن باشی؛ حذف برنامه ممکن است ذخیره محلی WebView را پاک کند.
