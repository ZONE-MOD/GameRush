# وضعیت انتقال Dino Rush به Godot

## در این پایه پیاده‌سازی شده

- پروژه مستقل Godot با خروجی هدف Android و Web.
- حرکت خودکار دایناسور، پرش، سرخوردن، موانع، برخورد و جمع‌آوری سکه.
- ده مرحله با نام‌ها و تم‌های رنگی برگرفته از بتا ۳.
- تغییر تدریجی تم مرحله دهم به فضای تیره و قرمز از داخل محیط.
- حالت بی‌نهایت با افزایش تدریجی سرعت.
- منوی افقی، جوایز روزانه، جعبه آزمایشی، فروشگاه غیرفعال تا اتصال API.
- کاتالوگ اسکین‌ها و هلمت‌های بتا ۳ در یک پچ پایه.
- سیستم دریافت کاتالوگ آنلاین پچ‌ها و ساخت خودکار کاتالوگ در GitHub Actions.
- فرم نمایشی ورود/ثبت‌نام با نام، رمز و شماره؛ داده‌ها در این نسخه فقط محلی‌اند.

## هنوز آنلاین/نهایی نیست

- احراز هویت واقعی، شناسه ۶ رقمی سراسری، جلوگیری سراسری از تکرار نام، تیک آبی و مدیریت بن/سکه؛ قرارداد و طرح D1 آماده شده ولی Worker هنوز پیاده‌سازی و deploy نشده است.
- مالکیت آنلاین اسکین، کدهای یک‌بارمصرف و پرداخت واقعی.
- انتقال تمام جزئیات بصری، افکت‌ها، موسیقی و کات‌سین HTML بتا ۳ به دارایی‌های بومی Godot.
- دوبله نهایی و فایل‌های صوتی باکیفیت.
- تست FPS و حافظه روی مدل‌های واقعی گوشی.

این تفکیک عمدی است تا قابلیت‌های محلی با امنیت آنلاین اشتباه گرفته نشوند.
