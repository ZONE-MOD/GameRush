# Game layer

- `main.gd`: screens, local demo profile, navigation and game flow.
- `runner_world.gd`: gameplay loop, obstacle spawning, coin collection and collision.
- `player.gd`: dinosaur movement and procedural rendering.
- `level_manager.gd`: ten stage names, palettes and speed progression.

The current Godot build is a playable first native foundation. The supplied HTML beta 3 is preserved in `legacy/` as a visual/feature reference; it has not been mechanically converted line-for-line.
