# سیستم پچ مستقل اسکین و هلمت

تمام اسکین‌ها و هلمت‌های موجود در بتا ۳ در `base_patch.json` قرار گرفته‌اند. بازی در شروع، پچ پایه و تمام فایل‌های `patch_*.json` را می‌خواند.

## اضافه کردن پچ جدید با یک فایل

1. فایل `templates/patch_TEMPLATE.json` را کپی کن.
2. نام فایل را مثل `patch_002_winter.json` بگذار.
3. برای هر اسکین و هلمت، `id` یکتا انتخاب کن. شناسه قبلی را دوباره استفاده نکن.
4. فایل جدید را مستقیماً در همین پوشه `graphics/skin_patches/` قرار بده؛ نه داخل `templates`.
5. فایل را به GitHub پوش کن.

GitHub Actions در هر بار انتشار، همه پچ‌ها را اسکن می‌کند و یک `patches/catalog.json` تجمیعی می‌سازد. بازی در اجرای بعدی، کاتالوگ آنلاین را دریافت و آیتم‌های جدید را به کلکسیون اضافه می‌کند. برای پچ‌های صرفاً رنگی و مبتنی بر طراحی procedural همین یک فایل JSON کافی است.

برای اسکین‌هایی که تصویر یا انیمیشن اختصاصی دارند، فایل‌های رسانه‌ای را هم در پوشه‌ای مثل `graphics/skins/<skin_id>/` قرار بده و در پچ به مسیر asset ارجاع بده؛ این نسخه اولیه فعلاً ظاهرها را با رنگ و شکل procedural رسم می‌کند.

## قوانین

- `id` باید یکتا و پایدار باشد.
- rarity یکی از `common`, `rare`, `epic`, `legend`, `mythic`, `ultimate` باشد.
- قیمت منفی (`-1`) یعنی فعلاً خرید مستقیم ندارد.
- `skins` و `helmets` می‌توانند خالی باشند، اما باید آرایه باشند.
- کاتالوگ آنلاین فقط اطلاعات نمایشی را می‌آورد؛ مالکیت و خرید واقعی باید از API سرور تأیید شود.
